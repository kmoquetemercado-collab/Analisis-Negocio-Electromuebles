Empresa: Electromuebles

Modelo de dominio, análisis de entidades, relaciones y tablas de base de datos

1. Objetivo del negocio

El negocio de electromuebles gestiona ventas, compras, inventario, caja, pagos, cobranzas, proveedores, clientes, sucursales, personal y banco. La base de datos deberá soportar todas las operaciones de administración, logística, facturación, tesorería y nómina.

Se trabaja con la cardinalidad: 1:1, 1:N y N:M.

2. Diferencia entre DEA, DERE y DER

DEA

Es el Diagrama de Entidad-Atributo. Incluye:

  • todas las entidades
  • sus atributos
  • claves primarias
  • claves candidatas
  • claves foráneas
DERE

Es el Diagrama de Entidad-Relación con fuerza de entidad. Incluye:

  • entidad fuerte
  • entidad débil
  • relación
  • cardinalidad
  • solo la clave principal y la relación
DER

Es el Diagrama Entidad-Relación general. Incluye:

  • entidades
  • relaciones
  • cardinalidad
  • clave primaria de cada entidad
Regla de entidad fuerte y débil

En relación directa, la entidad fuerte se representa con doble línea y la débil con línea simple. Ejemplo que indicó el profesor:

erDiagram CLIENTE ||--o{ FACTURA : genera

Fuerte CLIENTE
Débil FACTURA

Ejemplo de criterio: Cliente es fuerte respecto a Factura. Factura es débil respecto a Cliente porque depende de él para existir.

4. Relaciones principales del negocio

  • Provincia tiene muchas Ciudades (1:N).
  • Ciudad tiene muchas Sucursales (1:N).
  • Sucursal tiene muchos Empleados (1:N).
  • Cargo define muchos Empleados (1:N).
  • Empleado genera muchas Nóminas (1:N).
  • Vendedor atiende muchas Cotizaciones (1:N).
  • Cliente genera muchas Cotizaciones (1:N).
  • Cliente genera muchas Facturas (1:N).
  • Factura tiene muchas Devoluciones (1:N).
  • Factura puede tener una Entrega a domicilio (1:1).
  • Proveedor hace muchas Compras (1:N).
  • Compra genera Cuentas por pagar (1:1).
  • Cliente genera Cuentas por cobrar (1:N).
  • Caja se abre y cierra en la Apertura/Cierre de caja (1:N).
  • Banco tiene muchas Cuentas bancarias (1:N).
  • Cuenta bancaria tiene muchos movimientos de Depósito, Cheque y Transferencia (1:N).
  • Producto puede estar en muchos Almacenes mediante transferencias (N:M, a través de Transferencia de almacenes).

8. Resumen final

En el sistema de electromuebles existen 46 entidades de dominio distribuidas en 8 categorías. La estructura de base de datos está enfocada en:

  • Administración
  • Recursos humanos
  • Inventario
  • Ventas y facturación
  • Compras
  • Crédito y cobro
  • Caja
  • Banca y tesorería

En la práctica, las entidades más importantes para diferenciar fuerza y debilidad son:

  • Cliente es fuerte respecto a Factura.
  • Factura es débil respecto a Cliente.
  • Proveedor es fuerte respecto a Compra.
  • Compra es débil respecto a Proveedor.
  • Empleado es fuerte respecto a Nómina.
  • Nómina es débil respecto a Empleado.
