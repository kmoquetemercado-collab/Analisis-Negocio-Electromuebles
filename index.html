Conceptos Fundamentales

📊 DEA

Diagrama Entidad-Atributo

  • Muestra todas las entidades
  • Incluye atributos completos
  • Identifica claves primarias (PK)
  • Identifica claves foráneas (FK)
  • Nivel más detallado

🔗 DERE

Diagrama Entidad-Relación Extendido

  • Identifica entidades fuertes
  • Identifica entidades débiles
  • Muestra relaciones directas
  • Especifica cardinalidad
  • Entidad fuerte ║ (doble línea)
  • Entidad débil │ (línea simple)

🗄️ DER

Diagrama Entidad-Relación

  • Modelo general de relaciones
  • Cardinalidades: 1:1, 1:N, N:M
  • Base para crear tablas
  • Útil para diseño de BD
  • Menos detallado que DEA
